# Contributing to yunaremaia

## Reporting Issues

Please search for existing issues first. If none exist, open a new issue with the following template:

```markdown
## Description
...

## Steps to Reproduce
...
```

## Pull Requests

1. Fork the repository
2. Create a branch from `main`: `git checkout -b my-feature`
3. Make your changes
4. Run the test suite: `pytest`
5. Commit your changes: `git commit -m "feat: ..."`
6. Push to your fork: `git push origin my-feature`
7. Open a Pull Request

## Development Setup

```bash
# Clone your fork
git clone git@github:YOUR-USERNAME/yunaremaia.git
cd yunaremaia

# Install dependencies
pip install -e .
```
